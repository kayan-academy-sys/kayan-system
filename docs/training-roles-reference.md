# مرجع الأدوار والصلاحيات لنظام كيان (للتدريب الصوتي لاحقًا)
مصدر الحقائق: src/lib/permissions.js كما هو منشور فعليًا (تم استخراجه 2026-11-22).
هذا المرجع للاستخدام في سكربتات الفويس التدريجية لكل قسم بعد جاهزية النظام.

## الأدوار التسعة وأسماؤها العربية
- admin = مدير النظام (كل الصلاحيات *)
- general_supervisor = المشرف العام
- sales_manager = مدير المبيعات
- sales_team_leader = تيم ليدر المبيعات
- sales_staff = موظف مبيعات
- accounting_manager = مدير الحسابات
- accounting_staff = موظف حسابات
- reception = استقبال
- course_manager = مسؤول الكورسات والمجموعات

## المبيعات (sales)
- مدير المبيعات: يرى كل العملاء المحتملين، ينشئ ويعدّل ويوزّع العملاء (leads.assign)، يتابع الفريق (leads.monitor)، يدير الحضور الإداري (presence.manage)، ينشئ حجوزات ويرى كل الحجوزات، تقارير المبيعات + تصدير، عمولته الخاصة.
- تيم ليدر: عملاءه هو فقط (leads.view.own) + إنشاء/تعديل + متابعة الفريق، حجوزاته هو، عمولته الخاصة. لا توزيع عملاء، لا تقارير مبيعات.
- موظف مبيعات: عملاءه فقط، إنشاء/تعديل، حجوزاته فقط، عمولته الخاصة. لا متابعة فريق، لا تقارير.
- المشترك: لوحة التحكم، العملاء، عرض المجموعات/الباقات/الكورسات، الإشعارات، مساعد كيان (ai.use).

## الحسابات (accounting)
- مدير الحسابات: المدفوعات (عرض/إنشاء/إلغاء void)، الأقساط (عرض/إدارة)، المصروفات (عرض/إنشاء/إلغاء)، أنواع المصروفات، الخزائن/الحسابات (عرض/إدارة)، التحويلات (إنشاء/عرض)، التقفيلات (closings.manage)، إلغاء الحجوزات، العمولات (عرض الكل/إدارة/تنفيذ)، تقارير مالية + تصدير.
- موظف حسابات: مدفوعات (عرض/إنشاء فقط)، أقساط عرض، مصروفات (عرض/إنشاء)، حسابات عرض، تحويلات عرض، عمولات عرض الكل + إدارة، تقارير مالية. لا إلغاء مدفوعات/مصروفات، لا إدارة خزائن، لا تقفيلات، لا تنفيذ عمولات.

## الاستقبال (reception)
- لوحة الاستقبال، تسجيل وعرض الحضور، عرض العملاء، بحث الطلاب، عرض الأقساط المحدود (installments.view.limited)، عرض المجموعات والكورسات. لا حسابات، لا حجوزات.

## الكورسات (course_manager)
- إدارة الكورسات والمدربين والمجموعات والحصص (sessions.manage) والباقات، عرض الحضور، لوحة الاستقبال، تقارير مبيعات.

## المشرف العام (general_supervisor)
- تقريبًا كل شيء تشغيلي: كل العملاء + التوزيع + المتابعة، إدارة الكورسات/المدربين/المجموعات/الحصص/الباقات، كل الحجوزات + إنشاء، عرض المدفوعات/الأقساط/المصروفات/الحسابات (عرض فقط، لا إنشاء)، الاستقبال + تسجيل الحضور، تقارير مبيعات ومالية + تصدير، عمولات الكل، سجل المراجعة (audit.view)، طلبات المستخدمين (users.request)، الإشعارات، مساعد كيان.

## مسار العمل الأساسي (workflow)
1. العميل المحتمل يدخل (يدويًا/توزيع) → موظف مبيعات يتابعه.
2. حجز (orders.create) بباقة → أقساط تتولد.
3. دفعة تُسجل (payments.create) → تدخل الخزينة وتنعكس على لوحة التحكم.
4. الاستقبال يسجل الحضور؛ مسؤول الكورسات يدير المجموعات والحصص.
5. الحسابات تقفل وتصدر التقارير؛ العمولات تُحسب وتُنفذ حسب القواعد أعلاه.
